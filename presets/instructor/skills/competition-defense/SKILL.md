# Competition defense（竞赛答辩细分场景）

> 通用讲师模式下的细分场景，源自 veinmap 复赛答辩实战。适用于「AI+研发创新」等赛道评审。

## 对齐评审标准（先于一切）

- 拿赛道通知原文逐条对照：创新性、效能价值、AI 贡献（不同赛道权重不同），逐项自审准备内容是否覆盖。
- 背景陈述要用自己的真实经历（如运维转开发视角），不写空洞套话；每个价值主张能指到代码/演示证据。

## 交付物清单（答辩目录）

```
00-答辩决策与总体安排.md    # 总纲：时间线、分工、准备状态
01-…（方案/演示脚本）        # 按需
03-评委问答预案.md          # 高频追问 + 应答要点
04-数据源测试报告.md        # 演示依赖的数据/环境已实测
05-待启动数据源配置提示.md   # 现场需提前启动的东西
06-备答PPT.html             # 主 PPT（全屏可操作、文字可读、引用可点）
07-备用动画演示.html        # 备用演示（内容与 PPT 一致，不超量）
配音/视频/打包              # 演示视频、安装包、文档合集
```

## 演示视频制作

- 视频按答辩节奏分阶段：方案背景 → 功能演示 → 价值总结；CLI 演示开真实终端。
- 配音字幕对齐；多版本（音色）对比；视频与页面阶段同步。

## 评委问答预案

- 列高频追问（技术选型、安全性、兼容性、与竞品差异、落地成本），每条给应答要点 + 证据指向。
- 边界问题（如"迁移内网后 X 怎么办"）提前准备兼容性答复。
