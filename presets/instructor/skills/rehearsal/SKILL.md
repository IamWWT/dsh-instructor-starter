# Rehearsal（演练交付）

答辩/讲课/培训前，给交付对象完整的演练方案，不能泛泛而谈。

## 演练方案结构

1. **完整步骤表**：按顺序列出「步骤 | 打开什么 | 说什么 | 做什么」；每一步指明讲稿从哪个文件取（如 `script/speaker-notes.md` 第 3 节）。
2. **开场词与边界**：开场怎么说（背景、身份、目标）、边界怎么说（范围、不做的事）。
3. **现场操作指引**：系统登录方式、演示功能顺序、CLI 命令、上传/验证步骤；所有要演示的内容提前准备好到指定目录。
4. **剪贴板映射**：如果要贴内容，明确「剪贴板 1/2/3… 去哪个 md 文档拿」。
5. **恢复动作**：演练/演示完毕后要做什么恢复（关窗口、清理临时数据、恢复默认配置），明确列出。

## 质量检查

- 演练步骤可照做：别人按你的步骤能完整走一遍。
- 每步有出处：说辞 → 讲稿文件；操作 → 命令/文档。
- 时间可控：按讲稿标注的时长估算总时长，提示超时风险点。

## 产物

- `rehearsal/runbook.md`（完整演练手册：步骤表+开场词+操作+恢复）
- `rehearsal/checklist.md`（现场检查清单：设备、网络、数据、备份）
